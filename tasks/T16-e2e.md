## Goal
A real browser plays the main flows on every push, so a change that breaks the game fails CI instead of reaching the player. Unit tests cannot catch a blank screen, a dead button or a WebGL error.

## Write scope
- `e2e/**` (new): Playwright tests and helpers
- `playwright.config.ts` (new)
- `package.json`: add devDependency `@playwright/test` and script `"e2e": "playwright test"` (allowed by the Lead, see decisions.md 2026-10-23). No other new dependency.
- `.github/workflows/ci.yml`: add a job (or steps after the build) that runs `npx playwright install --with-deps chromium` and `npm run e2e`; upload the Playwright report as an artifact on failure
- `.gitignore`: `test-results/`, `playwright-report/`
- `src/main.ts`: only a DEV-only hook if you truly need one (inside `if (import.meta.env.DEV)`), never in the production build
- `docs/shots/T16-*.png`

## Requirements
1. `playwright.config.ts`: chromium only; `webServer` runs `npm run build && npm run preview` (tests the production build) on a fixed port; WebGL works headless (add the chromium flag `--use-angle=swiftshader` or `--enable-unsafe-swiftshader` if the canvas is black). Retries 1 in CI, 0 locally.
2. Select by role and visible text (`getByRole('button', { name: 'Start' })`), never by CSS class, so the UI design rounds (Wave 6) can restyle without breaking the tests. Where no stable name exists, add an `aria-label` request to "Questions" instead of adding classes.
3. Every test starts from an empty `localStorage` (a fresh context) unless it sets a save first.
4. Scenarios (one test each):
   1. Fresh player: onboarding to the 3-card result in under 90 s of test time; reload goes to home, not onboarding.
   2. Practice drill: read each card from the memorize HUD, then enter the same cards in recall by keyboard; the result shows a perfect score; the save in `localStorage` has one more drill.
   3. Quit mid-drill: Esc or Quit during memorize and during recall returns home and saves no drill.
   4. Daily Deck: two runs on the same day deal the same cards (read from the HUD).
   5. Settings persist: change glide to 0, colour-safe on, sound off; reload; values kept and `<html>` has class `color-safe`.
   6. Import/export: export downloads valid JSON (`page.waitForEvent('download')`); importing a hand-broken file shows an error and keeps the old save; importing a valid save replaces it.
   7. Shadow Walk: enter and exit; no console errors.
   8. Every test fails on any `console.error` or `pageerror` (shared fixture).
5. The whole suite runs in under 3 minutes locally. Write the time in "Report".
